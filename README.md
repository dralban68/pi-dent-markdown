# pi-dent-markdown

The `Markdown` tool of [pi-dent-agent](https://www.npmjs.com/package/pi-dent-agent), as a library:
outline, read, edit and link-check a Markdown file by its headings. It is not a pi extension by
itself; pi-dent-agent registers the tool from `makeMarkdownTool` and `markdownRuntime`.

Requires Node 26 or later and a pi that provides the extension API.
